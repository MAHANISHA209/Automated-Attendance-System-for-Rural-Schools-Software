# Automated Attendance System for Rural Schools

The Automated Attendance System for Rural Schools is a simple web-based application designed to help schools manage student attendance digitally.

## Project Description

This system allows administrators and teachers to manage students, classes, and attendance records easily. It reduces manual attendance work and provides quick access to attendance reports.

## Main Features

- Secure Login Page
- Admin Dashboard
- Teacher Dashboard
- Student Dashboard
- Student Management
- Teacher Management
- Class Management
- Daily Attendance
- Present, Absent and Late Status
- Attendance History
- Monthly Attendance Reports
- Attendance Percentage
- Notifications
- Profile Management
- Responsive Design

## Attendance Management

Teachers can select a class and date, view the student list, and mark each student as Present, Absent, or Late. Attendance records are stored in the database and can be viewed later through reports.

## Login

The system provides role-based login for different users such as Admin, Teacher, Student, and Parent.

## Technology Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite Database

## How to Run

Open the project folder in the terminal and run:

    python app.py

Then open the browser and visit:

    http://127.0.0.1:5000

## Project Workflow

Login → Dashboard → Manage Students → Select Class → Mark Attendance → Save Attendance → View Reports

## Purpose

The main purpose of this project is to provide a simple, efficient, and user-friendly digital attendance solution for rural schools.
